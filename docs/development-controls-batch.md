## 使用与限制

鼠标强调默认关闭。在现有画布面板开启后，可选光晕、箭头或十字，调整大小、强调层显示与点击扩散环。预览和导出共用源时间求值，裁剪及变速使用映射后的源时间；绘制直接进入目标画布，不新增全分辨率逐帧中间副本。设置沿用内部格式4的画布配置，支持撤销/重做，旧工程补齐默认值。

Qt 6.8.3 的 `QScreenCapture` / `QWindowCapture` 公开接口没有光标采集开关。原生鼠标已烧入录像，当前不能从视频中移除。“显示强调指针”只控制额外强调层；这项限制在界面中明确显示，不能称为完整原版光标替换。

暂停压缩视频、声音及鼠标时间线。摄像头暂停同步已实现源码路径，但本机没有真实摄像头，硬件行为尚未验收。区域录制、中断恢复、长期漂移与其余原版能力仍属完整首版范围。

实际预览检查覆盖 QMediaPlayer→保音高处理器→QAudioSink 的设备格式初始化与送出PCM；导出检查重新解码成片。两者已有通过证据，但不代替主观音质与声学loopback测量。编辑器实际拖动、跨片段播放与合成摄像头同步检查通过；最终构建通过，2.5秒编辑器成片回归通过；初始化时发现的空片段QML错误已修复，最终回归未出现 ReferenceError 或 TypeError。

## 最小复现

构建部署后，运行[Windows开发版说明](windows-development-build.md#光标保音高与录制控制批次)中的 cursor、audio-time-stretch、audio-packet、preview-audio、recording-controls、export-options 与 cursor-export 检查。每条检查使用新目录并核对退出码。预览测试播放测试声音；原始媒体、设备信息、绝对路径、详细JSON与事件日志只保存在本地忽略目录。公开内容仅保留本页与[验证摘要](validation/public-results.md)中的脱敏结论。
