## 启动与复现

双击根目录 `启动 ScreenPilot.cmd`，默认优先打开 `build/desktop/portable-ui/ScreenPilot.exe`。移动应用时保留完整部署目录。

构建使用 `scripts/build-windows.ps1 -QtRoot <Qt6-MSVC-kit> -Deploy`。现有编辑流程检查继续可用。截图检查使用自己生成的三秒短片，输出目录必须为空：

```powershell
$app = Resolve-Path '.\build\desktop\portable-ui\ScreenPilot.exe'
$source = Resolve-Path '.\generated-source.mp4'
$output = Join-Path $PWD 'probe-results\ui-snapshot-local'
& $app --ui-snapshot-smoke-test $source --editing-result-directory $output
```

该检查生成正常1280×860与最小860×640窗口截图及导出面板截图；保存截图本身不等于视觉验收，需查看是否拥挤、裁切、缺少入口或预览异常。截图和运行日志仅存放本地忽略目录。
