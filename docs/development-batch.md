# Windows 四项开发批次

2026-10-13。依据固定 Mac 版本及 `parity-checklist.md`，按用户要求一次整合声音导出、自动运镜、时间线和摄像头。Windows/C++/Qt6；不开展 Linux。本页记录本批次交付及必要检查，不改变完整首版范围。

| 项目 | 本批次行为 | 必要检查 |
| --- | --- | --- |
| 声音导出 | MP4保留声音、静音MP4、剪辑后仅音频M4A；不覆盖既有文件 | 生成带声音素材，三种结果实际解码、时长及轨道检查 |
| 自动运镜 | 可选开启；倍率、过渡、弹簧、安全区域跟随；源时间确定性计算 | 固定轨迹跟随、边界连续性、设置历史及保存重开 |
| 时间线 | 实际缩略图与音频采样波形、拖动/按钮重排、1/1.5/2/4/8/12/20/50/100倍速度档位 | 源时间映射/历史/重开；重排变速结果实际导出解码 |
| 摄像头 | 设备/尺寸选择、镜像预览、独立素材；后期形状/位置/大小/取景及同步偏移 | 布局夹具、素材复制重开、生成摄像头同步导出；有设备时短录制解码 |

整合采用内部工程版本4并兼容1/2/3。预览和导出共用运镜求值与摄像头绘制；摄像头原始素材不烧入录屏，可后期改布局。关闭摄像头不启动设备，只有用户开启时使用设备。

当前已验证：工程模型的映射、历史和保存重开检查通过；三种导出、多速度，以及摄像头正负偏移和隐藏的合成导出检查通过；真实时间线解码得到7张缩略图与7个非零音频采样；摄像头合成布局检查通过。本机无摄像头，真实设备录制明确跳过。实际编辑器鼠标拖动及恢复顺序、选中状态、2倍速跨片段播放与摄像头同步检查通过；录制、画布、撤销重做、保存重开及1080×1080导出解码回归通过。

本批次初始实现的变速会改变音高；后续[录制控制批次](development-controls-batch.md)已为预览和导出加入WSOLA保音高处理，仍未对齐原版 spectral 算法。摄像头偏移以首个预览帧估计，未验收精确硬件同步；稀疏音频峰值不等于完整波形。长录制、多设备、长视频导出、取消恢复、完整Mac视觉仍未验收；Mac工程互通已按用户决定排除，完整原版范围继续保留。最小构建和复现命令见[Windows开发版说明](windows-development-build.md)。

源码实现、构建和实际运行分别记录，未通过的项目不写成已验收。原始媒体、设备信息、截图和详细日志仅保存在忽略的本地 `probe-results`。
