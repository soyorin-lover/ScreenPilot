# ScreenPilot

ScreenPilot 是以 [DogSC macOS 原版](https://github.com/laogou717/dogsc)为主要参照，使用 **C++ / Qt** 开发的 Windows 录屏及轻量编辑应用，Windows 版完成后再逐步移植 Linux。

目标是将固定版本 Mac 原版的完整产品体验先带到 Windows：功能、界面、操作流程、工程语义和成片效果尽量一致。首版按完整对齐原版的首个交付版本定义，不以精简 MVP 代替。本项目为独立开发项目，不代表原作者的官方跨平台版本。

## 当前状态

**2026-10-13：项目规划阶段。**

目前仅有首版项目说明、需求和路线图，尚未提供 C++ / Qt 应用、安装包或可运行演示。下文所列能力均为开发目标；平台支持和工程兼容性须通过实际测试后确认。

- **主要参照：GitHub 上的 Mac 版 DogSC。** 以其源码、项目模型、算法、界面和实际行为为依据。
- **辅助参考：已有 Electron Windows 适配版。** 可以借鉴平台问题与实现经验，不以其功能缺失、工程格式或技术选型定义本项目。
- 首次参考基线：[上游提交 `fa24059`](https://github.com/laogou717/dogsc/tree/fa24059a9ba7e769152b3c1de047d96aca873e1c)。后续更新基线时，记录差异与兼容影响。
- 不机械翻译 Apple 框架代码。保留产品规则和核心算法，当前只实现 Windows 系统能力；Linux 后端待 Windows 版完成后再设计与实现。

## 产品目标

面向需要制作软件演示、操作教程和产品展示的用户，提供一条完整流程：

**选择录制来源 → 录制画面与声音 → 保存工程 → 剪辑与调整效果 → 导出成片。**

首版覆盖固定参考版本的完整能力，以下为能力分组摘要，不代替逐项对照清单：

- 屏幕、窗口、区域及原版 iOS 设备来源，摄像头、麦克风与系统声音录制，录制标记与悬浮备忘录；设备来源的 Windows 路径待验证。
- 原版录制编码与分辨率选项、系统声音范围选择，以及录制辅助窗口排除等行为。
- 独立记录鼠标轨迹与点击，用于后期光标美化和自动运镜。
- 时间线分割、裁短、删除、重排、变速与恢复，缩略图、波形、吸附、效果复制粘贴，以及撤销和重做。
- 自动跟随、手动缩放、开场动效、屏幕 3D、摄像头布局与动画、光标样式与点击反馈。
- 比例、裁切、留白、背景、圆角、阴影、贴图、画面柔化、样机外框与场景预设。
- 保存与重新打开 `.dogscproject` 工程。
- 暂停/继续、重录/丢弃、中断录制恢复、摄像头同步校准和项目源文件导出。
- MP4 视频与 M4A 音频导出，原始素材分辨率、1080p、1440p、4K 与 30/60 FPS 选项，支持进度显示和取消。
- 原版设置、语言切换、项目管理及更新等辅助流程的对应 Windows 体验。

以上原版能力均属于首版对齐范围，不能自动推迟到首版之后。开发可以按完整小流程分批交付内部版本；内部版本不代表完整首版完成。[原版能力对齐清单](docs/parity-checklist.md)记录固定基线的源码依据、行为要求、验收方法与待实测项，避免将上游 main 的新增功能混入基线。首版边界与验收要求见 [需求与路线图](docs/requirements.md)。

仅因真实平台约束无法等价实现时，记录验证依据、影响与替代方案，并与用户确认差异；不能自行删减功能。原版产品品牌、作者专属资源和 Apple 分发设施不直接照搬，采用适合本项目的对应内容与机制。

## 工程兼容与效果对齐

以 Mac 原版 `.dogscproject` 为兼容目标，按阶段验证读取、渲染与保存。**扩展名相同不等于工程互通。**

- 保留上游字段含义、枚举值、时间单位、默认值和版本规则。
- 遇到暂不支持的效果，应明确提示并保留原始数据；不能静默删除或覆盖原工程。
- 使用固定输入检查核心算法，使用参考帧和参考视频比较成片效果。
- 预览与导出共用场景计算和效果规则，避免两套实现产生差异。
- 操作系统权限面板、快捷键映射和窗口装饰按平台适配；应用内光标效果、布局与操作行为仍以原版为标准。影响体验的差异需要记录、验证并确认。

## 技术方向

- **语言与构建：** C++、CMake，优先评估 C++20 与 Qt 6.8 或更新版本。
- **界面：** Qt Quick / QML，自定义视觉与交互以接近 Mac 原版。
- **核心：** 工程模型、时间线、鼠标轨迹、运镜与场景计算独立于平台采集代码。
- **系统后端：** 当前只实现 Windows；保持媒体与工程规则和系统接口分离，Linux 移植后续再做，不提前建设 Linux 后端或复杂跨平台抽象。
- **媒体与渲染：** 在验证 GPU 合成、编解码和声音同步后确定；FFmpeg 是候选工具，尚未确定最终依赖与分发方式。

本项目不使用 Electron 界面。Qt 本身不等于完整的录屏编辑引擎，具体性能和支持能力以验证结果为准。
